# KRT Workspace browser assets

[Open KRT Workspace](https://hamzah22221.github.io/krt-workspace-app/)

This repository contains compiled public browser assets only. Team records,
attachments and milestones are stored in Supabase and require an authorized
account. The publishable API key is intentionally public and grants no team
access by itself. No service key, database password, or team spreadsheet is
included here.

Generated from the private krt-workspace source repository. Rebuild the source
and replace these assets when releasing a new frontend version.
